04 — SIX REVENUE CHANNELS

Repo: PAULIS-PLACE — ADW scripts in adws/, Celery tasks in backend/workers/revenue_tasks.py
Reader model: GLM 5.2 (text-only)

1. Purpose

Six autonomous revenue channels run on cron. Each channel has one ADW script (SSSF pattern), one Celery task that dispatches to it, and one set of downstream events that flow to Zernio (posts) and the 3D world (avatar scenes). Every channel obeys the same cost cap: $0.50 per run.

3. The shared channel structure

Every channel ADW has the same four phases, in this order:

  1. Research (scanner profile) — gather signals. Read-only.
  2. Rank (scorer profile) — pick the best opportunity.
  3. Produce (designer or channel-specific worker) — turn the pick into an artifact.
  4. Validate (publisher profile) — check the artifact against platform rules. On pass, emit revenue.channel_output_ready.

4. Channel-by-channel briefs

CH1 · AFFILIATE CONTENT ENGINE

Goal: generate short-form content that promotes AI-tool affiliate links with recurring commissions. Publisher character posts them.

Input signals: ProductHunt launches this week, AppSumo deals, Reddit r/SaaS threads.

Output artifacts: per pick, three drafts (one for TikTok, one for Instagram Reels, one for X thread). Each includes the affiliate link with UTM tags ?utm_source=paulisplace&utm_campaign=<tool-slug>.

Zernio dispatch: emits three revenue.channel_output_ready events, one per platform draft.

Cost cap: $0.30/run.

CH2 · DOMAIN FLIP INTELLIGENCE

Goal: identify brandable domains at auction with high resale potential.

Input signals: GoDaddy auctions expiring in the next 7 days, DropCatch feed.

Output artifacts: a shortlist of 5 domains with rationale, valuation estimate, and target buyer profile. Written to icm/memory/decisions/domains_<date>.md. No auto-purchase — human confirms in the lounge via a trigger_purchase voice command.

Zernio dispatch: optional weekly summary post on X for audience-building.

Cost cap: $0.40/run.

CH3 · FACELESS-YT SERVICES

Goal: offer competitor-breakdown reports for faceless-YouTube channel owners as a service (Gumroad/Stan Store product).

Input signals: trending channels in target niches (finance, self-improvement, history retold).

Output artifacts: one sample report per week (published free as lead magnet), 20+ paid report SKUs generated per week (each ~$47).

Zernio dispatch: LinkedIn and X posts announcing new reports; Reddit posts in niche-relevant subs (rate-limited to protect subreddit standing).

Cost cap: $0.50/run.

CH4 · MICRO-APPS (Creem-paywalled)

Goal: ship one small tool per week — a niche calculator, a specific-purpose generator, a boring-problem solver — priced $9–$47 with Creem paywall.

Input signals: Reddit "how do I…" posts with high engagement in target niches, Twitter complaints.

Output artifacts: spec brief for the tool. Human implements it. Once shipped, Creem product SKU is created via API and paywall is wired.

Council involvement: the "should we build this?" decision goes through subsystem 02 Council. Advocate makes the case (niche size, willingness to pay), Critic tears down (existing tools, technical debt), Judge rules.

Zernio dispatch: launch post on X, ProductHunt entry drafted (posted manually), LinkedIn post.

Cost cap: $0.50 for ideation, separate budget for the Creem creation (no AI cost, just API).

CH5 · EBOOK PIPELINE (KDP)

Goal: ship niche non-fiction ebooks to Kindle Direct Publishing, ride keyword traffic, collect royalties.

Input signals: KDPRocket-style keyword gaps, Google Trends for evergreen how-to searches.

Output artifacts: per week, one ebook outline (Thursday research). Daily, one chapter (Monday–Sunday). Book cover generated via Replicate.

Zernio dispatch: book launch post, Reddit-friendly announcements in relevant subs, TikTok short "here's a book I wrote" (optional, human-approved).

Cost cap: $0.50 for research, $0.20/day for chapter generation.

CH6 · THRIFT FLIP LISTINGS

Goal: generate research briefs for eBay/Poshmark reselling — the human sources the items, the AI writes the listings.

Input signals: Terapeak sold-listings feed, TrendGirl feed, eBay category velocity.

Output artifacts: a weekly "hunt list" of 20 items likely to sell fast, with condition benchmarks, keyword-optimized titles, and a description template per SKU.

Zernio dispatch: optional TikTok "here's what I found" posts (human-approved before publish).

Cost cap: $0.40/run.

5. The shared cost-and-safety guardrails

  1. Each channel run declares its predicted cost before dispatch. Gateway rejects if predicted > cap.
  2. All 6 channels together must not exceed $5/day. The Redis counter is shared. If exceeded, remaining channel runs for the day are queued to tomorrow.
  3. No channel may publish to Etsy, Printify, Creem, or KDP without human approval on the specific artifact. The channels produce briefs and drafts — the human hits "publish" through a lounge voice command or the frontend.
  4. Every channel writes an ops report to icm/memory/ops/<date>/ch<N>_<correlation-id>.json.

6. Acceptance criteria

  1. All 6 channel ADW files exist and each has the 4 phases in section 3.
  2. The schedule in section 2 is expressed in celery_app.py's beat schedule.
  3. Each channel emits revenue.channel_output_ready with a valid envelope on success.
  4. Cost caps are enforced with pre-flight checks; violations halt the run.
  5. The 3D world (subsystem 07) receives events per the "Character on screen" column and animates the matching avatar.
